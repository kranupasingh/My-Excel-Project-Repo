# Excel Retail & Sales Data Analysis 📊

## Overview
This project was completed during the **Data Technician Bootcamp (Week 1: Excel)**.  
It focuses on analyzing retail and sales datasets using **Excel’s advanced features** to transform raw data into meaningful insights.

## Skills Demonstrated
- **Formulas & Functions**
  - `SUM`, `SUMIF` – aggregate totals with conditions
  - `AVERAGE`, `AVERAGEIF` – calculate averages with filters
  - Date functions: `DATE`, `MONTH`, `YEAR`
  - `UNIQUE` – extract distinct values
  - `VLOOKUP` – lookup and match data across tables
  - `SWITCH` – simplify conditional logic

- **Data Management**
  - Filtering and sorting datasets
  - Cleaning and organizing retail/sales records

- **PivotTables**
  - Summarizing large datasets
  - Grouping by categories (e.g., product, region, month)
  - Calculating totals and averages dynamically

- **Data Visualization**
  - Charts (bar, line, pie) to highlight trends
  - PivotCharts for interactive analysis
  - Visual storytelling of sales performance

## Key Insights
- Identified top-performing products and regions
- Analyzed monthly and yearly sales trends
- Built dashboards to support decision-making in retail operations

## Tools Used
- Microsoft Excel (Bootcamp Week 1 focus)
- Retail & sales datasets provided during training

## Learning Outcome
This project strengthened my ability to:
- Use **Excel formulas** for efficient calculations
- Apply **PivotTables** for dynamic reporting
- Create **visualizations** that communicate insights clearly
- Manage and analyze real-world retail data with confidence
